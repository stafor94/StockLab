# 안내 기능 점진 적용 및 로컬 QA 지표

## 적용 원칙

1. 모든 안내는 현재 게임 상태와 이미 공개된 정보만 사용한다.
2. 튜토리얼과 체크리스트는 게임 계산 규칙을 바꾸지 않는다.
3. 기존 세이브는 v10으로 마이그레이션하고, 완료·건너뛴 튜토리얼 상태는 새 게임에서도 보존한다.
4. 주문은 선택 사항이며 최초 무주문 장 시작에서만 확인한다. 자동진행은 이 확인창으로 막지 않는다.
5. 모바일 320px부터 데스크톱까지 overflow, 44px 터치 영역, 키보드 포커스, reduced-motion을 회귀 테스트한다.

## 로컬 전용 QA 이벤트

`stocklab.qa-events` LocalStorage에는 최근 200건까지만 저장할 수 있다. 네트워크 전송, 사용자 식별자, 실제 종목 식별자, 기기 지문은 포함하지 않는다.

- `guidance_action`: 안내 행동 사용
- `first_market_open`: 첫 장 시작
- `first_day_closed`: 첫 장 마감
- `tutorial_completed` / `tutorial_skipped`: 튜토리얼 완료·건너뛰기
- `guidance_blocked`: 안내 단계에서 진행이 막힌 경우

이 데이터는 개발·QA용이며 게임 세이브와 독립적으로 관리한다.
