# 안내 기능 점진 적용 및 로컬 QA 지표

## 릴리스 순서

1. **1차:** 모든 플레이 상태에서 항상 보이는 다음 행동 카드와 도움말을 제공한다.
2. **2차:** 첫 사용자 튜토리얼과 첫 거래일 체크리스트를 활성화한다.
3. **3차:** 로컬 QA 결과와 사용성 테스트를 바탕으로 문구와 강조 강도만 조정한다. 게임 계산 규칙은 바꾸지 않는다.

## 로컬 전용 QA 이벤트

이벤트는 브라우저의 `stocklab.qa-events` LocalStorage에 최근 200건만 저장한다. 네트워크 요청, 사용자 식별자, 실제 종목 식별자, 기기 지문을 포함하거나 외부로 전송하지 않는다. QA 담당자가 개발자 도구에서 직접 내보낸 경우에만 집계한다.

- `guidance_action.actionCount`: 새 저장에서 첫 `first_market_open`까지 필요한 행동 수.
- `first_day_closed`: 첫 거래일 마감 완료 여부.
- `tutorial_completed` / `tutorial_skipped`: 튜토리얼 완료·건너뛰기 여부.
- `guidance_blocked.step`: 진행 중 막힌 안내 단계를 집계해 가장 잦은 단계를 찾는다.

ISO 시각은 이벤트 순서와 중복 확인에만 사용하며 개인을 식별하지 않는다. 저장 초기화와 QA 이벤트 초기화는 독립적이다.
